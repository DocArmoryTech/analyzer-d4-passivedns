# Contributing

## Development Setup

1. Fork and clone the repo.
2. Install dependencies:
   ```bash
   poetry install --with dev
   ```
3. Run tests:
   ```bash
   poetry run pytest
   ```

## Coding Standards

- Follow PEP 8.
- Use type hints.
- Write docstrings.

## Pull Requests

- Create a feature branch.
- Submit a PR to `main` with passing tests.
